# TaskFlow

Projekt zaliczeniowy – Programowanie aplikacji internetowych MVC 
Autor: Jakub Rycembel, nr albumu: 162288

## Temat 

Prosta aplikacja, która ma służyć do planowania zadań. Aplikacja będzie obsługiwać podstawowe funkcje, takie jak: priorytet, termin, oznaczanie zadań wykonanych i edycje zadań (dodawanie/usuwanie). 

## Struktura repozytorium 

- czesc1-servlet-jsp – aplikacja Servlet + JSP + JSTL (Tomcat 10.1) 
- czesc2-spring-boot – aplikacja Spring Boot + Thymeleaf 
- docs – dokumentacja projektu
